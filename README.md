## Sobre este repositório

Este repositório contém os scripts, exemplos e automações apresentados no livro **SQL — Do Zero ao Domínio**, com foco em:

- Modelagem de bancos de dados relacionais
- Escrita e análise de consultas SQL
- Manipulação e integridade de dados
- Performance, índices e planos de execução
- Uso de SQL em ambientes corporativos
- Integração entre SQL e Inteligência Artificial

Todos os scripts seguem boas práticas e são documentados para uso seguro em ambientes reais.

## Assistente de estudos com Inteligência Artificial

Este projeto também disponibiliza um conjunto de instruções para configurar um assistente de IA especializado no conteúdo do livro **SQL — Do Zero ao Domínio**.

O assistente foi desenvolvido para atuar como um tutor técnico, auxiliando o leitor a:

- Compreender comandos e conceitos da linguagem SQL;
- Criar, revisar e otimizar consultas;
- Identificar erros e sugerir correções;
- Estudar modelagem de dados e relacionamentos;
- Compreender índices e planos de execução;
- Explorar os recursos do MySQL 8.4 e do SQL procedural.

### Como utilizar

O arquivo de instruções está disponível na pasta `Agente` deste repositório:

📄 [Assistente de Estudos — SQL (Markdown)](Agente/assistente-estudos-sql-mysql.md)

Basta utilizar seu conteúdo nas instruções personalizadas ou no recurso de projetos da plataforma de Inteligência Artificial escolhida.

Quando a plataforma permitir, recomenda-se adicionar também o livro e os arquivos complementares como materiais de referência.

**Importante:** o arquivo configura o comportamento e as orientações do assistente, mas não concede automaticamente acesso ao banco de dados nem permite executar comandos SQL. Essas capacidades dependem dos recursos e das permissões disponibilizados pela plataforma utilizada.
