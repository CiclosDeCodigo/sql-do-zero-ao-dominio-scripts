## Sobre este repositório

Este repositório contém os scripts, exemplos e automações apresentados no livro **SQL — Do Zero ao Domínio**, com foco em:

- Modelagem de bancos de dados relacionais  
- Escrita e análise de consultas SQL  
- Manipulação e integridade de dados  
- Performance, índices e planos de execução  
- Uso de SQL em ambientes corporativos  
- Integração entre SQL e Inteligência Artificial  

Todos os scripts seguem boas práticas e são documentados para uso seguro em ambientes reais.

## Estrutura do projeto

## Objetivo

Fornecer uma base sólida e progressiva para que alunos e profissionais:

- Aprendam SQL com exemplos aplicáveis  
- Implementem boas práticas  
- Criem soluções reais para o dia a dia de TI  
- Apliquem Inteligência Artificial nas tarefas
